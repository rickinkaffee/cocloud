# 2026-11-16 通用功能同步

本次同步以当日服务器上部署的扩展行为为参照，修改可维护源码并重新构建。公开版是独立发行版，未复制运行实例、状态目录或已部署的可执行文件。

## 本次更新

- Android 更新到 1.0.8：拍照附件、相机 URI 授权、安装回执与版本状态核对；构建时使用自己的服务地址及签名身份。
- 网页增加拍照入口，通过现有附件校验与上传流程处理照片；取消拍照保留草稿。
- 右侧增加 Floe 共享浏览器页签，切换面板保留浏览器及原面板状态；需先部署浏览器网关。
- 增加会话轮次、工具步骤、Token、缓存命中、上下文、首响应延迟和输出速度统计。输出速度按输出区间计算；缺少计量时显示未知或文本估计，不能用作计费依据。
- 新建空项目保持可见；仅有归档会话的项目按归档证据隐藏，跨环境分别处理。
- 移动端防止切换会话或重建编辑器时抢焦点；明确点击输入区后才恢复编辑。
- 记忆入口和统计组件支持中文／英文扩展语言选项。
- 未使用 Git 的工作目录在首次捕获基线时初始化仓库，使检查点及回滚可用；普通仓库检测不修改目录。
- 增加 Codex 技能启用／停用入口和后端接口，仅可修改当前提供方已发现的技能，需提供方管理权限，以服务端确认的状态为准。技能文件由安装者自行配置。

## 与原部署的边界

- 不包含原部署的账号、API Key、服务器地址、聊天、记忆内容、项目文件、浏览器用户资料、个人规则或技能。
- 不包含个人余额服务、私有模型发现及专有 Claude/Cursor TypeScript SDK 集成。
- 公开版保留默认 30 天会话策略，没有复制原部署的超长期浏览器登录策略；重新安装需自行配对。
- 原部署的整套界面汉化及构建产物注入脚本未整体复制；本次中文／英文切换仅覆盖上述扩展组件。通用核心界面继续采用源码基线的语言。
- 入口位置及组件结构允许与原部署不同，不保证二进制或界面逐像素一致。

## 验证方法

回归使用合成数据、新建临时目录和模拟提供方，不读取个人聊天或调用付费模型。覆盖拍照附件取消／接入、面板状态保留、移动端焦点、统计计算、归档目录、新仓库检查点、技能协议写入／拒绝未知路径及管理权限。重新执行网页和服务器类型检查、正式构建以及 Android 构建。

Android 真机相机／安装流程、真实代理账号和模型服务仍需要安装者在自己的设备上验收。仓库不附 APK、签名密钥或预配置账号。
